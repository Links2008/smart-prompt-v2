步骤2: 导出歌曲列表

💡 使用说明

推荐方式：使用第三方迁移工具

  1. 点击「导出完整列表」按钮
  2. 点击「复制到剪贴板」
  3. 前往 TuneMyMusic 或 Spotlistr
  4. 选择「任意文本」→ 粘贴 → 选择Apple Music作为目标
  5. 工具会自动匹配并创建歌单

手动方式：逐首搜索

  1. 点击歌单中的任意歌曲
  2. 自动复制搜索词到剪贴板
  3. 在Apple Music中粘贴搜索
  4. 添加到您的歌单
