## 📖 使用说明

### 1. 获取 QQ 音乐歌单链接

1. 打开 QQ 音乐 App 或网页版
2. 进入要迁移的歌单
3. 点击「分享」
4. 复制歌单链接

### 2. 粘贴链接并获取

1. 在首页的输入框中粘贴链接
2. 点击「获取歌单」
3. 等待系统解析和匹配

### 3. 导出并导入到 Apple Music

1. 选择导出格式（推荐 CSV）
2. 打开 Apple Music
3. 文件 → 导入 → 选择导出的文件

## 🔄 错误处理详解

### 1. 网络与请求错误

```python
# 重试策略：
- 第1次失败 → 等待1秒
- 第2次失败 → 等待2秒
- 第3次失败 → 等待5秒
- 限流检测 → 读取 Retry-After 头
```

### 2. 数据解析错误

```python
# 处理策略：
- 空字段 → 自动填充 "未知"
- 解析失败 → 跳过记录 "解析失败"
- 特殊字符 → 转义处理
- 页面结构变化 → 提示错误
```

### 3. 匹配失败错误

| 类型 | 处理方式 |
|------|---------|
| 无版权 | 标记，建议手动搜索 |
| 版本不匹配 | 降级匹配，记录版本不一致 |
| 译名不匹配 | 自动别名匹配+拼音 |
| 分数过低 | 直接标记失败 |

## 📊 匹配策略

- **多轮搜索策略：歌名 → 歌手 → 专辑 → 翻译**
- **分数算法：使用 difflib 计算相似度
- **版本识别：自动检测 Remix/Live/伴奏等版本
- **别名库：内置常见歌手中英文互译
